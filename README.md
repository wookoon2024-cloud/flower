## 💡 왜 만들었나요?

- **감정노동 심화** – 악성 민원 폭언, 반복 민원, 격무로 공직자의 직무 스트레스와 번아웃 위험이 커지고 있습니다.
- **기존 상담의 이용 장벽** – 대면 상담은 예약·방문이 부담스럽고 주변 시선과 비밀 유지가 걱정되며, 정기 심리검사는 일회성 진단에 그칩니다.
- **해결 방향** – 업무 PC 안에서 **예약 없이 바로 쓰는 1:1 비대면 마음 돌봄**. 업무를 방해하지 않고, 매일 들여다보고 싶게 만드는 반려화분 형태로 만들었습니다.

## 🌟 핵심 기능

### 1. 💬 끝까지 들어 주는 여러 턴 고민 상담 (v2.1.0 신규)
한 번 답하고 끝나는 챗봇이 아니라, 실제 상담처럼 대화를 이어 갑니다.

| 턴 | 마음지킴이의 역할 | 예시 |
| :---: | :--- | :--- |
| ① | 공감하며 무슨 일이 있었는지 묻기 | "그럼요, 제가 끝까지 들어드릴게요. 오늘 어떤 일이 있었어요?" |
| ② | 노력을 알아주고 그때 마음을 묻기 | "그 상황에서도 끝까지 응대하신 거 정말 애쓰셨어요. 그때 마음은 어땠어요?" |
| ③ | 감정 인정 · 함께 숨 고르기 · 대처 안내 | "폭언을 들은 건 당신 잘못이 아니에요. 4초 들이쉬고 6초 내쉬어 보세요. 반복되면 특이민원 대응 절차대로…" |
| ④ | 기관 상담(EAP) 안내하며 마무리 | "마음이 계속 무겁다면 기관 상담 프로그램도 꼭 활용해 보세요." |

- 주제별 흐름: **악성 민원 · 상사 · 동료 · 업무 과부하 · 일반 고민**
- 추천 질문 버튼(직장 고민 상담소, 악성 민원/무리한 요구, 상사·동료 갈등, 업무 과부하 토닥토닥 등)으로 막막할 때도 바로 시작
- AI 연결 시에는 같은 원칙(공감 → 되묻기 → 대처 → 기관 안내)을 시스템 프롬프트로 지시하고, **AI가 끊기거나 키가 없어도 내장 응답 엔진이 같은 4턴 상담을 이어 갑니다.**

### 2. 🤫 일할 땐 조용히, 쉴 때 먼저 챙기기
- 키보드·마우스 입력을 감지해 **작업 중에는 절대 말을 걸지 않습니다.**
- 30분 넘게 쉬지 않고 일한 뒤 손을 떼는 순간, 스트레칭과 물 한 잔을 먼저 권합니다.
- 출근 인사, 점심시간, 퇴근길 격려처럼 시간대에 맞춰 먼저 말을 걸어 옵니다.

### 3. 📊 마음 날씨 – 감정 기록과 7일 추이
- 대화 속 감정을 **기쁨 · 열정 · 평온 · 피로 · 힘듦** 5단계로 기록하고 7일 그래프로 보여 줍니다.
- 번아웃 신호를 스스로 먼저 알아차릴 수 있습니다.

### 4. 🪴 매일 찾아오게 만드는 반려화분
- 물·햇빛·쓰다듬기와 대화로 **새싹부터 만개까지 6단계 성장**
- 품종 6종, 받침대 6종, 반려동물 5종(고양이·강아지·토끼)으로 나만의 화분 꾸미기
- 만개한 화분은 화원에 졸업시키고 새 품종 씨앗 심기, **업적 112종**, 매일 포춘 쿠키
- 꿀벌·나비 같은 생태계 손님이 찾아와 단조로운 업무 화면에 생기를 더함

### 5. ✉️ 간단한 업무 도우미 (AI 연결 시)
- 문장 다듬기(공문·메일을 정중하게), 3줄 아이디어, 긴 글 3줄 요약, 할 일 우선순위 정리

## 🚀 실행 방법

### 방법 1. 단독 실행파일 (권장)
1. [`마음지킴이_실행파일_v2.1.0.zip`](마음지킴이_실행파일_v2.1.0.zip) 내려받기 → 아무 폴더에 압축 해제
2. `마음지킴이.exe` 더블클릭 → 첫 화면에서 호칭 · 화분 품종 · 이름 정하기 → **키우기 시작**
3. 화면 오른쪽 아래 작업표시줄 위에 화분이 나타납니다. **클릭**하면 상태바(물·햇빛·대화·화원·설정), **우클릭**하면 전체 메뉴

### 방법 2. 소스코드로 실행
```bash
git clone https://gitlab.aigov.go.kr/westock/flower.git
cd flower
pip install -r requirements.txt
python test_suite.py   # 단위 테스트 14개
python main.py
```

### 방법 3. 실행파일 직접 빌드
```bash
python build_exe.py        # dist/마음지킴이.exe 생성
python package_release.py  # 실행파일·소스 배포 zip 생성 (git에 등록된 파일만 포함)
```

### 시연 순서 (약 3분)
1. 화분 클릭 → 💧 물 · ☀️ 햇빛 → 성장 반응 확인
2. 우클릭 → **대화하기** → 추천 질문 **"🍵 직장 고민 상담소"** → 이어서 "민원인이 계속 소리를 질러서 힘들었어" → 감정 이야기 → 마무리까지 4턴 대화 확인
3. 우클릭 → **나의 화원 & 마음 도감** → 마음날씨 · 상점(받침대·반려동물) · 업적 · 포춘 탭
4. 우클릭 → **환경 설정 → AI API 설정** → 프리셋을 바꿔 모델 교체 구조 확인

## ⚠️ 알려진 제약 사항

- **전문 상담 대체 아님** – 일상적인 마음 환기·정서 지원 도구입니다. 위기 상황은 기관 상담 프로그램이나 전문 상담기관을 이용해야 합니다.
- **감정 분석** – 대화 문장의 키워드 기반 추정이며 의료적 진단이 아닙니다.
- **AI 답변** – AI 연결 시 답변 품질은 연결한 모델에 따라 다릅니다. 인터넷망 상용 AI는 기관 정보보안 지침을 확인하세요.
- **보안 프로그램** – 매체제어·백신이 서명 없는 실행파일을 막으면 예외 등록이 필요합니다.
- **오픈소스** – PySide6(LGPLv3), requests(Apache-2.0), urllib3(MIT), Pillow(MIT-CMU), PyInstaller(GPL + 빌드 결과물 배포 예외). 재배포가 제한되는 구성요소는 없습니다.

### 📈 6단계 진화 여정
1. **1단계**: 🌱 씨앗 & 새싹 (Seedling)
2. **2단계**: 🌿 어린 줄기 (Sprout)
3. **3단계**: 🪴 자라나는 잎새 (Growing Stem)
4. **4단계**: 🌷 첫 꽃망울 (Budding)
5. **5단계**: 🌸 탐스러운 개화 (Blooming)
6. **6단계 (Master)**: 👑 영광의 만개 & 결실 (Full Bloom & Graduation)
   - 6단계 만개 달성 시 **"화원 명예의 전당"에 영구 졸업 등록** 후 새로운 품종의 씨앗을 입양할 수 있습니다.

```text
flower/
├── ai_plant/
│   ├── ai_client.py           # LLM 워커(CLOVA GOV·OpenAI 호환), 내장 응답 엔진, 여러 턴 상담 흐름
│   ├── config.py              # 설정 로더 (API 키는 로컬 DB 보관)
│   ├── database.py            # SQLite 저장소 · 마음 날씨 · 자동 복구
│   ├── plant_engine.py        # 6단계 성장 · 상태 감쇠 · 업적 · 상점
│   ├── achievements_data.py   # 업적 112종 정의
│   ├── shop_data.py           # 받침대 6종 · 반려동물 5종
│   └── ui/                    # 화분 위젯 · 말풍선 · 대화창 · 화원/도감 · 환경 설정 · 첫 실행 창

├── package_release.py         # 배포 zip 생성 (개인 데이터 제외 검사 포함)
├── test_suite.py              # 단위 테스트 14개
├── requirements.txt           # 의존성 (보안 패치 버전 고정)
└── INSTALL_GUIDE.md           # 상세 설치 안내
```
